Student Enrollment System

Project Overview

The Student Enrollment System is a Python-based desktop application developed to manage student enrollment records using a graphical user interface and MySQL database.

The application allows users to add new student records, view enrolled students, and delete enrollment records using Student ID.

Technologies Used

* Python
* MySQL
* Tkinter
* MySQL Connector

Key Features

1. Student Enrollment

* Enter Student ID and personal details.
* Add student enrollment records.
* Store enrollment date automatically.

2. View Student Records

* Retrieve student records from the MySQL database.
* Display Student ID, Name, and Course details.

3. Delete Enrollment

* Delete enrollment records using Student ID.
* Display a success message when a record is deleted.
* Show a warning if the Student ID is not found.

4. Input Validation

* Check that all required fields are filled.
* Display error messages for missing information.

Database

MySQL is used to store student enrollment information.

Database Name: student_db

Table Name: students

Key Learnings

* Connecting Python applications with MySQL.
* Performing INSERT, SELECT, and DELETE operations.
* Building desktop applications using Tkinter.
* Handling user input and validation.
* Managing student records through a database.
